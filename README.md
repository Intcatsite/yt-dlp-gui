# yt-dlp GUI

Настольное приложение для [yt-dlp](https://github.com/yt-dlp/yt-dlp) на Electron: вставляете ссылку — получаете видео или аудио, без консоли и флагов командной строки.

Реализовано по дизайну, экспортированному из Claude Design (`yt-dlp-gui.dc.html`).

## Возможности

- **Загрузка** — видео или аудио (MP3), выбор качества (до 4K для видео, до 320 kbps для аудио), субтитры (в том числе автоматические, с встраиванием при наличии ffmpeg), несколько ссылок сразу (режим плейлиста).
- **Очередь** — реальный прогресс загрузки (без имитации), пауза/возобновление (докачка через `--continue`), отмена, ограничение числа одновременных загрузок.
- **История** — список завершённых загрузок с размером файла и датой, открытие папки с файлом, очистка.
- **Настройки** — пути к `yt-dlp`/`ffmpeg`, шаблон имени файла (`%(title)s.%(ext)s` и т.д.), тёмная/светлая тема, акцентный цвет, проверка обновлений yt-dlp.

## Требования

- В комплекте с приложением уже идёт бинарник `yt-dlp` (для Windows-сборки). Если он не найден — приложение попробует найти `yt-dlp`/`ffmpeg` в `PATH`.
- Для слияния видео+аудио в один файл и извлечения аудио (MP3) нужен **ffmpeg** — на Windows он не бандлится (лицензия/размер), установите его отдельно и добавьте в `PATH` ([ffmpeg.org](https://ffmpeg.org/download.html), либо `winget install ffmpeg`). Без ffmpeg приложение по-прежнему скачивает видео, но только в едином (progressive) формате, без выбора качества выше того, что доступно в один поток.

## Разработка

```bash
npm install
npm start
```

## Сборка

```bash
npm run build:win     # dist/*.exe (установщик NSIS + portable)
npm run build:linux   # dist/*.AppImage
npm run build:mac     # dist/*.dmg
```

Каждая команда сборки сначала скачивает подходящий бинарник `yt-dlp` в `resources/bin/` (см. `scripts/fetch-ytdlp.js`), затем собирает приложение через `electron-builder`.

## Готовый `.exe`

Собирается автоматически в GitHub Actions (`.github/workflows/release.yml`) при пуше тега `vX.Y.Z` и публикуется как GitHub Release. Актуальную сборку также можно скачать со страницы [Releases](https://github.com/Intcatsite/yt-dlp-gui/releases) или как артефакт последнего запуска [Actions](https://github.com/Intcatsite/yt-dlp-gui/actions).

## Технические детали

- **Electron** (main + preload + vanilla JS renderer, без фреймворков) — окно без системной рамки со своим тайтлбаром, как в дизайне.
- Загрузка запускается как отдельный процесс `yt-dlp` на ссылку; прогресс парсится через `--progress-template` (без хрупкого regex по человекочитаемому выводу).
- «Пауза» останавливает процесс `yt-dlp`, «возобновить» — перезапускает его с `--continue` (докачка недокачанного файла).
- Настройки и история загрузок хранятся в JSON-файле в `userData` (`app.getPath('userData')/store.json`).
